┌──────────────────────────────────────────────────────────────────────────────┐
│                         3. QUERY PATTERNS                                     │
└──────────────────────────────────────────────────────────────────────────────┘

    User Query: "List floats with oxygen in Arabian Sea"
            │
            ▼
    ┌─────────────────────────┐
    │  Groq SQL Generator     │
    │  - Recognize "oxygen"   │
    │  - Map to DOXY          │
    │  - Detect spatial query │
    └───────────┬─────────────┘
                │
                ▼
    ┌─────────────────────────────────────────────────────────────┐
    │  Generated SQL:                                             │
    │  SELECT DISTINCT p.float_id                                 │
    │  FROM argo_bgc_profiles p                                   │
    │  JOIN argo_bgc_measurements m                               │
    │    ON p.global_profile_id = m.global_profile_id             │
    │  WHERE m.bgc_parameters ? 'DOXY'  ← JSONB existence check  │
    │    AND p.latitude BETWEEN 10 AND 25                         │
    │    AND p.longitude BETWEEN 50 AND 75                        │
    │    AND (m.bgc_parameters->'DOXY'->>'qc')::int <= 2          │
    └───────────┬─────────────────────────────────────────────────┘
                │
                ▼
    ┌─────────────────────────┐
    │  PostgreSQL Execution   │
    │  Uses GIN index         │
    │  Fast lookup            │
    └───────────┬─────────────┘
                │
                ▼
    ┌─────────────────────────┐
    │  Results:               │
    │  - Float 5906527        │
    │  - Float 5906528        │
    │  - Float 5906529        │
    └─────────────────────────┘


┌──────────────────────────────────────────────────────────────────────────────┐
│                    4. JSONB OPERATORS REFERENCE                               │
└──────────────────────────────────────────────────────────────────────────────┘

    Operator │ Description              │ Example
    ─────────┼──────────────────────────┼────────────────────────────────────
       ?     │ Key exists?              │ bgc_parameters ? 'DOXY'
       ?&    │ All keys exist?          │ bgc_parameters ?& ARRAY['DOXY','CHLA']
       ?|    │ Any key exists?          │ bgc_parameters ?| ARRAY['DOXY','CHLA']
       ->    │ Get JSON object          │ bgc_parameters->'DOXY'
       ->>   │ Get value as text        │ bgc_parameters->'DOXY'->>'value'
       #>    │ Get nested object        │ bgc_parameters#>'{DOXY,value}'
       #>>   │ Get nested value as text │ bgc_parameters#>>'{DOXY,value}'

┌──────────────────────────────────────────────────────────────────────────────┐
│                    6. PERFORMANCE CHARACTERISTICS                             │
└──────────────────────────────────────────────────────────────────────────────┘

    Query Type                    │ Performance │ Index Used
    ──────────────────────────────┼─────────────┼─────────────────
    Existence check (?)           │ O(log n)    │ GIN index
    Multiple keys (?&, ?|)        │ O(log n)    │ GIN index
    Value extraction (->)         │ O(1)        │ After key lookup
    Full table scan               │ O(n)        │ Avoided with index
    JOIN with profiles            │ O(log n)    │ FK index + GIN
